## Release 1.0.1 – Changelog Summary

This patch release hardens **AvalynxToast** against XSS, refines the timer bar rendering, and adds a neutral `default` toast type. All changes are backward compatible with 1.0.0.

* **Security: HTML escaping for messages**
  The `message` is now escaped before it is rendered via `innerHTML`, preventing injected HTML such as `<script>` or `<img onerror=...>` from being executed. Rendered HTML is no longer interpreted; plain text content is unaffected.

* **New `default` type**
  `'default'` is accepted as a toast type alongside the eight Bootstrap color types. It keeps the plain Bootstrap toast look and renders the timer bar with a neutral translucent background. Invalid types still fall back to `'info'`.

* **Timer bar polish**
  The timer bar is now positioned absolutely at the bottom edge of the toast with a rounded bottom-left corner, so it overlays the toast like a progress bar instead of stacking below the body.

* **Metadata clean-up**
  Fixed the author name typo (`an the` → `and the`), aligned package descriptions to "toast notification system", added the `message` keyword and removed a leftover debug file (`runner-fix.tmp`).

* **Quality Standards**
  78 unit tests cover all public behaviour with 100% statement, branch, function and line coverage.

**Compatibility**: Backward compatible
