## Release 1.0.0 – Changelog Summary

This milestone release marks the first stable version of **AvalynxToast**, providing a lightweight, dependency-free toast notification system built on top of Bootstrap >=5.3. It follows the same vanilla JavaScript approach as the rest of the Avalynx library family.

* **Initial Stable Release**
  AvalynxToast is ready for production use as a sibling library to AvalynxAlert and AvalynxModal, all sharing the same lightweight, framework-independent approach.
  Establishes the public API: `AvalynxToast(message, type, options)` with type-safe options for `title`, `subtitle`, `image`, `headerless`, `duration`, `position`, `closeable`, `autohide`, `width`, and `onClose`.

* **Toast Types and Positioning**
  Supports all Bootstrap color schemes (`primary`, `secondary`, `success`, `danger`, `warning`, `info`, `light`, `dark`) with type-specific background colours for the header and timer bar via CSS variables.
  Six predefined positions (`top-left`, `top-center`, `top-right`, `bottom-left`, `bottom-center`, `bottom-right`) append toasts to a Bootstrap `toast-container` with `p-3` padding, matching the Bootstrap docs best practice.

* **Header Customisation**
  Optional `title` (bold, left-aligned), `subtitle` (muted, right of the title), and `image` (small avatar at the start of the header) cover the common Bootstrap toast patterns.
  The `headerless` flag renders the simpler Bootstrap "Custom content" layout with only the body and a vertically centred close button.

* **Bootstrap Dependency Integration**
  Uses `bootstrap.Toast` for show/hide handling and the `hidden.bs.toast` event for the `onClose` lifecycle callback; no other framework dependencies are required.
  Build produces both classic (`dist/js/avalynx-toast.js`) and ESM (`dist/js/avalynx-toast.esm.js`) bundles alongside the stylesheet.

* **Examples and Quality Standards**
  Eleven runnable HTML examples (including highlight.js syntax highlighting and a dark-mode toggle) demonstrate every option and the random/50-50 patterns.
  72 unit tests cover all public behaviour with 100% statement, branch, function and line coverage.
**Compatibility**: Backward compatible
